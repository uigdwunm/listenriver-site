Local-first

默认在本机处理

ListenRiver is designed as a local workstation. Cloud processing is not the default path and should only happen after a clear user choice.

Inspectable

每一步都有产物

Projects keep durable files such as extracted WAV audio and project metadata under the project directory, so outputs can be played, exported, and inspected.

Project-based

以项目目录管理

Each imported media file becomes a project with explicit step folders. Later processing can build on the existing project artifacts.

Implemented now

Current completed step

The current packaged flow imports media, extracts one full-band working WAV, writes project metadata, and lets the user play or export that WAV.

  1. Import video or audio media
  2. Create the project directory
  3. Write steps/02-extract-audio/audio/original.wav
  4. Write project.json
  5. Play or export the extracted WAV

Boundaries

Clear about what mixed audio can and cannot do

Vocal extraction is not the same as isolating one chosen person. Background speech can remain speech and may appear in extracted vocal segments.

A single mixed track can contain overlapping speakers, music, reverb, wind, and compression. ListenRiver will not promise perfect separation from that source.

# ListenRiver Website

Public GitHub Pages website and release-download repository for ListenRiver / 听川.

This repository is intentionally separate from the private ListenRiver application source. It contains only the static website and public release metadata/assets.

## Local Preview

```bash
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173`.

## GitHub Pages

Publish from:

```text
Branch: main
Folder: /
```
